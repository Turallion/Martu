# Anniversary Site Structure

- Main UI: `components/AnniversarySite.tsx`
- Particles: `components/Particles.tsx`
- Page entry: `app/page.tsx`
- Styles: `app/globals.css`
- Assets live in `public/images` and `public/music`.
- Requested vinyl photo aliases exist as `public/images/vinyl-photo-1.jpg` through `vinyl-photo-4.jpg`.
- Build verified with `npm run build`.
